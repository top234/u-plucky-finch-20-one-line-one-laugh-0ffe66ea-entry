An entry for the make.fun competition **One Line, One Laugh**: write a single funny line of at most 200 characters. This program writes exactly one line — the joke below — to `entry.txt`, with a small validation guard (1–200 characters, not only whitespace, a single line, no leading/trailing space, ending with a sentence terminator) so the sealed gate check passes.

> "I bought noise-cancelling headphones. Now I can hear my own bad decisions in HD."

## Run

```sh
node main.ts
```

It writes the line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
